# Comunica-o-entre-3-Redes-Distintas
Este repositório contém a documentação completa de um laboratório prático de Redes. O objetivo principal do projeto foi construir, cabear, endereçar e validar a conectividade e o roteamento entre três segmentos de redes locais corporativas distintas (Redes de Classes A, B e C) utilizando o simulador **Cisco Packet Tracer**.
